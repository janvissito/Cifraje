Cifrado César

Sustitución monoalfabética histórica empleada por Julio César. Cada letra se desplaza $k$ posiciones módulo 26:

C = (P + k) mod 26

Mantiene mayúsculas, minúsculas, espacios y signos intactos.

📡

Código Morse

Codificación telegráfica binaria de puntos (.) y rayas (-).

Letras separadas por ' ' y palabras por ' / '

Descomposición NFKD automática para transformar caracteres como é, á, ñ, ç en letras base Morse.

🔄

Inversión de Texto

Invierte completamente la cadena de caracteres de extremo a extremo (texto[::-1]).

f(f(x)) = x (Función involutiva)

La operación de cifrar y descifrar es estrictamente idéntica y simétrica.
