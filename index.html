Xifratge Cèsar

Substitució monoalfabètica històrica emprada per Juli Cèsar. Cada lletra es desplaça $k$ posicions mòdul 26:

C = (P + k) mod 26

Manté majúscules, minúscules, espais i signes intactes.

📡

Codi Morse

Codificació telegràfica binària de punts (.) i ratlles (-).

Lletres separades per ' ' i paraules per ' / '

Descomposició NFKD automàtica per transformar caràcters com è, à, ç en lletres base Morse.

🔄

Inversió de Text

Reverteix completament la cadena de caràcters d'extrem a extrem (text[::-1]).

f(f(x)) = x (Funció involutiva)

L'operació de xifrar i desxifrar és estrictament idèntica i simètrica.
